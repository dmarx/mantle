# DP-013: Presentation is free to change; durable identity is not

Wording, layout and labels are presentation: change them whenever a better
one appears. Anything something outside mantle depends on is identity:
change it only with an alias or a migration.

Why: a renamed label costs nothing. A renamed URL breaks every inbound link,
and a renamed manifest key breaks every producer that writes it. The two
look alike in a diff and cost nothing alike.

Applied here:

- **URLs are source paths** ([ADR-001](../record/decisions.d/ADR-001.md) R4), and anchors are the producer's, so
  moving a record onto mantle breaks no link. A page that moves gets a
  redirect entry, not a dead URL.
- **Manifest keys are a contract** with every producer. Renaming one is a
  schema version bump, read side by side with the old one for a release.
- **A test selects by identity** (a data attribute, a page code), never by
  visible text, so a copy edit can't break it.
