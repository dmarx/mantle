# DP-007: No silent refusal

When mantle can't do something, it says so, and says why. It never quietly
does nothing. **A blank page is not a state.**

Why: nothing happening and everything working look the same from outside
([LU-DP-015](https://github.com/dmarx/luria/blob/main/docs/design-principles.md#dp-15)). A refusal that explains itself teaches the reader the tool's
model. A silent one teaches them the tool is broken, and they stop trusting
the parts that work.

Applied here:

- A page that can't be fetched or rendered shows the reason on the page:
  which URL failed, with which status, or which construct the renderer
  rejected.
- A manifest of a schema version this build doesn't read is refused by
  name, with the versions it does read.
- The build fails loudly when it was asked to publish nothing (an empty
  manifest, a source directory with no markdown). An empty site is never a
  green build.

The expensive corollary: every *partial* result needs saying too. A search
over a sharded index that failed to load one shard says which results may
be missing. It doesn't present the rest as complete.
