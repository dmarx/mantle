**The survey.** The owner asked which of nucleation's and strata-g's
decisions and principles mantle should adopt. Two read-only workers each
swept one record from its generated index (strata-g: 256 ADRs; nucleation:
151) and ranked candidates. The principles of all three projects were read
directly. Nucleation's content schemes and strata-g's domain features
(graphs, backends, its UI) were out of scope, apart from any general lesson
they carry.

**Adopted now**, because they apply before there is code, or are how the work
itself is done:

**Held for the first code pull request.** Each should arrive with its first
application, as [ADR-005](../../record/decisions.d/ADR-005.md) asks, so it is recorded here rather than adopted in
the abstract:

- **CI:**
  - job bodies live in make or npm targets that the workflows call, never in
    YAML alone ([SG-ADR-122](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-122.md));
  - a docs-only change skips the code jobs, with the filter written as
    exclusions from `**` and `.github/` never excluded ([SG-ADR-176](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-176.md)). mantle's
    own site build must not be gated that way;
  - diagnostic artifacts upload on failure only, and everything published
    has a retention rule ([SG-ADR-210](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-210.md), [SG-ADR-201](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-201.md)).
- **Code shape:**
  - logic lives in framework-free modules with unit tests ([SG-ADR-005](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-005.md));
  - version, commit and the manifest versions read are baked into the shell
    and shown ([SG-ADR-088](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-088.md)).
- **Testing:**
  - a readiness signal per document (`data-render-state`) and a
    `window.__mantle` hook for tests, never `networkidle` or pixels
    ([SG-ADR-033](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-033.md), [SG-ADR-035](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-035.md));
  - parallel e2e at a measured worker count, with a serial escape hatch
    ([SG-ADR-180](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-180.md));
  - timing budgets measured serially as medians with a measured tolerance,
    and byte budgets checked exactly ([SG-ADR-221](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-221.md));
  - a registry of isolated fixture runs that exits non-zero when any fails
    ([SG-ADR-202](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-202.md)).
- **Robustness:**
  - a render crash leaves a way out: optional engines such as the LadybugDB
    wasm module load by dynamic import behind a capability probe, inside a
    boundary that shows the error ([SG-ADR-226](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-226.md));
  - fetching is honest about CORS, with typed failures, `Retry-After`,
    per-host concurrency and abort on navigation ([SG-ADR-113](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-113.md), [SG-ADR-195](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-195.md),
    [SG-ADR-120](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-120.md), [SG-ADR-118](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-118.md)).
- **UI:**
  - the renderer is a custom element in a shadow root, with sanitized
    markdown, so the shell is one embedder among many ([SG-ADR-237](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-237.md),
    [SG-ADR-238](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-238.md); [ADR-001](../../record/decisions.d/ADR-001.md) R5);
  - platform-first accessibility rules ([SG-ADR-125](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-125.md), [SG-ADR-151](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-151.md)).

**Considered and not taken**, with the reason:

- nucleation's dialectic regime (no argument schemes here);
- its staging branch and nightly promotion (mantle's `main` deploys; revisit
  on the batch trigger, as [ADR-005](../../record/decisions.d/ADR-005.md) says);
- its adoption review of Proposed decisions ([NU-ADR-124](https://github.com/dmarx/nucleation/blob/main/record/decisions.d/ADR-124.md)), until about ten
  are pending;
- strata-g's self-hosted-runner policy (mantle uses hosted runners);
- its state-management and Tailwind choices (no framework chosen yet).

**A trap for the next survey.** strata-g's principles render with unpadded
anchors (`#dp-22`) while its files are padded (`DP-022.md`). Citing them as
`SG-DP-022` through a remote with a `document:` entry produces the right
anchor, which was checked against the rendered page before trusting it.
