# ADR-007: Logic lives in framework-free modules with unit tests; browser tests wait on declared render state; time and bytes are measured differently

## Context

Most of what mantle can get subtly wrong is algorithmic:

- validating a manifest and refusing a version ([ADR-001](ADR-001.md));
- mapping a source path to a URL (R4);
- resolving links and anchors;
- choosing shard and pagination thresholds (R3).

Its rendering is asynchronous by design: fetch the markdown, then render it
in the browser. And its requirements are budgets on size and time (R1–R3),
checked as a series (R6).

strata-g settled each of these after paying for it, and the owner runs them
there today. Each rule below cites its source as its application ([ADR-005](ADR-005.md)).

## Decision

*Proposed.*

- **Framework-free core** ([SG-ADR-005](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-005.md)). Logic that doesn't need the DOM or a
  UI framework lives in `src/core/`, imports neither, and is unit-tested
  (vitest, no DOM). The order is:
  1. extract the logic;
  2. write the failing test;
  3. implement;
  4. wire it back in.

  Components stay thin.
- **Declared readiness** ([SG-ADR-033](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-033.md), [SG-ADR-035](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-035.md)):
  - Every rendered document carries `data-render-state` = `loading`,
    `rendered` or `error`, with the reason on the element when it is `error`
    ([DP-007](../../docs/design-principles.md#dp-7)).
  - Tests wait on that, never on `networkidle`, timeouts or pixel positions.
  - A `window.__mantle` hook exposes the loaded manifest and each document's
    render state.
  - Tests select by identity, a data attribute or a page code, never by
    visible text ([DP-013](../../docs/design-principles.md#dp-13)).
- **Parallel e2e at a measured width** ([SG-ADR-180](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-180.md)). Fixtures are
  parallel-safe by construction: an ephemeral-port static server per worker,
  a fresh browser context per test, and no ordering. The worker count comes
  from a speedup curve measured on the GitHub-hosted runners it runs on, not
  `auto`. A serial run (one worker) is always available, for a readable
  failure.
- **Fixture runs are a registry** ([SG-ADR-202](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-202.md)). The fixture trees are:
  - a luria record;
  - a plain markdown directory ([DP-011](../../docs/design-principles.md#dp-11)'s second consumer);
  - a large generated tree, for the budgets.

  They are registered in one list, and each builds and is checked in
  isolation. The runner prints a pass/fail/skip table and exits non-zero if
  any failed. A missing precondition is a skip, said as one.
- **Bytes exactly, time statistically** ([SG-ADR-221](https://github.com/dmarx/strata-g/blob/main/docs/decisions/ADR-221.md)):
  - Output bytes are deterministic, so a byte budget (R2, R3) is an exact
    check, run after the report shows the expected page count ([DP-009](../../docs/design-principles.md#dp-9)).
  - Time is not deterministic on shared runners. A time budget (R1) is
    checked only as the median of at least three serialized runs, against a
    tolerance measured on mantle's own runs, never a single timing, and never
    from the parallel suite.
  - Each data point records its runner type and input size.

## Alternatives considered

- **Logic in components, tested through the browser.** Slow to run, and a
  failure says a page looked wrong, not which rule broke.
- **Waiting on `networkidle` or fixed sleeps.** It passes on a fast machine
  and flakes on a slow one, and says nothing about whether a document
  actually rendered.
- **Gating on one timed run.** strata-g measured 9.1% median and 93.7% worst
  per-test variation at 4 parallel workers, against 0.5% and 1.8% serialized.
  A single timing on a shared runner is noise with a threshold.

## Consequences

- The first code pull request sets up `src/core/` with vitest, and
  Playwright Test with the readiness contract.
- Every new piece of logic arrives with its unit test.
